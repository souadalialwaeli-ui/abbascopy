# 🎙️ دليل تشغيل VoiceForge — بديل Applio للموبايل

تطبيق **VoiceForge** يتيح لك تدريب نماذج واستنساخ وتحويل الأصوات بالذكاء الاصطناعي (RVC v2) من هاتفك مباشرة عبر متصفح الويب (PWA)، مع استغلال بطاقة الـ GPU المجانية في **Google Colab** للمعالجة والتدريب.

---

## 🚀 ملخص طريقة العمل (Architecture)

1. **الخادم (Backend):** يعمل داخل Google Colab (Python + FastAPI) ويعتمد على محرك RVC الأساسي من مشروع Applio.
2. **نفق الاتصال (Tunnel):** يتم استخدام **Cloudflare Tunnel (`trycloudflare.com`)** المدمج مجاناً وتلقائياً **دون الحاجة لأي حساب أو تسجيل في ngrok**.
3. **الواجهة (Frontend):** تطبيق PWA مبني بـ React و Tailwind يعمل على أي هاتف (Android / iPhone) ويمكن تثبيته كأيقونة على الشاشة الرئيسية.
4. **الربط (Sync):** 
   - خيار يدوي سريع: نسخ الرابط الظاهر في Colab ولصقه في صفحة إعدادات التطبيق.
   - خيار تلقائي (اختياري): إدخال رابط قاعدة بيانات Firebase Realtime Database ليتم تحديث الرابط في التطبيق تلقائياً عند كل تشغيل.

---

## 📱 الخطوة 1: تشغيل خادم Google Colab

1. افتح [Google Colab](https://colab.research.google.com).
2. اضغط على **File (ملف) > Upload notebook (رفع دفتر ملاحظات)** ثم اختر الملف:
   ```
   voiceforge/colab/VoiceForge_Server.ipynb
   ```
3. من القائمة العلوية في Colab، تأكد من تفعيل كارت الشاشة GPU:
   - اذهب إلى **Runtime (وقت التشغيل) > Change runtime type (تغيير نوع وقت التشغيل)**.
   - اختر **T4 GPU** ثم اضغط حفظ.
4. شغّل الخلايا بالترتيب:
   - **الخلية 1 (الإعداد والتثبيت):** تقوم بربط Google Drive وتثبيت مكتبات Applio و Cloudflared.
   - **الخلية 2 (تشغيل الخادم):** تقوم بتشغيل خادم FastAPI وإنشاء نفق Cloudflare وإظهار رابط الخادم العام:
     ```
     📱 Server URL:
     👉 https://random-words.trycloudflare.com
     ```
   - **الخلية 3 (إبقاء الجلسة نشطة):** تمنع Colab من إيقاف الجلسة تلقائياً.

## 📲 الخطوة 2: تشغيل واستخدام التطبيق على الموبايل

### التشغيل المحلي للتطوير:
```bash
cd voiceforge/frontend
npm run dev -- --host
```
سيظهر لك رابط محلي على شبكة الـ Wi-Fi (مثال: `http://192.168.1.X:5173`) يمكنك فتحه من متصفح هاتفك مباشرة.

### النشر المجاني على الإنترنت:
يمكنك رفع مجلد `frontend` مجاناً على **Vercel** أو **Netlify** أو **GitHub Pages** ليكون لديك رابط HTTPS دائم لتطبيقك (مثال: `https://my-voiceforge.vercel.app`).

### تثبيت التطبيق كـ PWA على الهاتف:
- **في Android (Chrome):** اضغط على قائمة الثلاث نقاط ثم اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home screen)** أو **"تثبيت التطبيق"**.
- **في iPhone (Safari):** اضغط على زر المشاركة (Share) ثم اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.

## 🔗 الخطوة 3: ربط التطبيق بالخادم

1. افتح تطبيق VoiceForge على هاتفك.
2. اذهب إلى تبويب **الإعدادات (Settings)**.
3. ألصق الرابط الذي حصلت عليه من Colab (مثال: `https://xxxx.trycloudflare.com`).
4. اضغط **"حفظ واتصال"**.
5. ستتحول النقطة في الشريط العلوي إلى **أخضر (متصل)** وسيظهر اسم كارت الشاشة GPU (مثل Tesla T4).

*(ملاحظة: إذا وضعت رابط Firebase في Colab والإعدادات، سيتصل التطبيق تلقائياً دون الحاجة لنسخ ولصق الرابط في كل مرة).*

## 🎤 كيفية الاستخدام

### 1. تحويل الأصوات (Inference):
1. اذهب إلى تبويب **"تحويل"**.
2. اختر النموذج الصوتي من القائمة المنسدلة.
3. سجّل صوتك مباشرة من الميكروفون أو ارفع ملف صوتي (WAV / MP3).
4. اضبط نغمة الصوت (Pitch) — مثلاً `+12` لتحويل صوت رجل إلى امرأة، أو `-12` للعكس.
5. اضغط **"تحويل الصوت"**، وخلال ثوانٍ ستسمع النتيجة ويمكنك تنزيلها.

### 2. تدريب نموذج جديد (Training):
1. اذهب إلى تبويب **"تدريب"**.
2. اكتب اسماً للنموذج.
3. ارفع تسجيلات صوتية نقية للشخص المراد استنساخ صوته (10-30 دقيقة مقاطع صوتية مفضلة).
4. اضغط بالتسلسل:
   - **1. رفع البيانات**
   - **2. المعالجة المسبقة (Preprocess)**
   - **3. استخراج الميزات (Extract Features)**
   - **4. بدء التدريب (Train)**
5. ستتابع تقدم التدريب بالوقت الفعلي عبر شريط التقدم ونسب الخسارة (Loss G / Loss D).
6. عند الانتهاء، يُحفظ النموذج تلقائياً في حسابك على **Google Drive** في مجلد `VoiceForge/models`.
